# 🎮 Retro Game Portfolio

Website portofolio dengan tema game retro piksel.

## 📁 Struktur File

```
WebHimakom/
├── index.html        ← File utama website
├── style.css         ← Seluruh styling retro
├── script.js         ← Interaktivitas & animasi
├── assets/
│   ├── avatar.png       ← Foto profil kamu
│   ├── infografis.png   ← Gambar infografis Tugas 3
│   ├── tugas2.pdf       ← File PDF Tugas 2 (ganti dengan file aslimu)
│   └── tugas4.mp4       ← Video Tugas 4 (ganti dengan file aslimu)
└── README.md
```

## 🚀 Cara Pakai

1. Buka `index.html` di browser
2. Atau gunakan Live Server di VS Code untuk pengalaman terbaik

## ✏️ Cara Kustomisasi

### Ganti Data Pribadi
Edit bagian berikut di `index.html`:
- **Nama, NIM, Jurusan, dll** → Cari `profil-nama`, `profil-nim`, dll.
- **Bio** → Cari elemen `profil-bio`
- **Social media links** → Ganti href pada `social-github`, `social-instagram`, dll.

### Ganti File Tugas
- **Tugas 2 (PDF):** Ganti file `assets/tugas2.pdf` dengan file PDF aslimu
- **Tugas 3 (Infografis):** Ganti file `assets/infografis.png` dengan file infografismu
- **Tugas 4 (Video):** Ganti file `assets/tugas4.mp4` dengan file videomu

### Ganti Foto Profil
Ganti file `assets/avatar.png` dengan foto profilmu sendiri.
